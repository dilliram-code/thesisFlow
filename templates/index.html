ℹ️ About ThesisFlow

An intelligent, open academic platform designed to make complex scientific preprints intuitive, computational, and verifiable.

Core Architecture

Built with a high-performance Python backend (FastAPI, SymPy, NumPy, SciPy) and a pure HTML5/CSS3/ES6+ client. Does not depend on heavy frontend framework bundles.

Safe Symbolic Math

All mathematical expressions are validated through SymPy AST with word-boundary code injection filtering. Zero arbitrary evaluation of user strings.
